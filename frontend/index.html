使用指南

GoalScope · 足球视频智能分析系统 V3.0

1
上传足球视频

在首页上传区拖拽或点击上传视频（支持 MP4、MOV 格式）。视频上传后会自动预览，文件名处可点击重新选择。

2
选择分析模式并开始分析

视频就绪后，选择分析模式（精彩事件检测 / 多目标跟踪 / 全部分析），点击开始分析，系统将自动完成全局追踪与深度分析，无需手动干预。

3
查看分析结果

分析完成后，可在以下页面查看结果：

首页 — 球员素质分析（AI 深度评估） 精彩视频 — 高光集锦播放、时间轴浏览、片段下载 多目标追踪 — 追踪视频播放、MOT 指标快览 评测指标 — MOTA / Precision / Recall / F1 / ID Switches 详细数据
常见问题
Q: 分析进度卡住？ → 首次运行需加载 YOLO 模型（约 1~3 分钟），CPU 模式下推理较慢，请耐心等待
Q: 视频无法播放？ → 请使用 Chrome 或 Edge 最新版浏览器
Q: 评测指标显示 N/A？ → 请先完成至少一次视频分析，再点击「刷新计算」
